Checking your receipt

One payment. Only the details you choose to share.

CHECK IT WITHOUT THE SERVER

The signature is Ed25519. Paste the merchant's public key, which you should get from the merchant by another route, and your browser checks the signature itself. No request is sent.

Merchant public key (Base64URL, SPKI Base64, or PEM)

This key was filled in by the same server that issued the receipt. It shows the receipt is consistent with that server, not that the server is who it claims to be. Compare the fingerprint with one the merchant gave you elsewhere.

What this proves, and what it does not
  • Proves: the merchant who issued this receipt signed these exact fields, and its own records confirm the invoice was paid. The merchant saw the payment with its viewing key. If a shown value changes, the signature check will fail.
  • Does not prove: anything the buyer chose not to reveal. It also does not let a stranger check the payment without trusting the merchant's key and server (in this demo, the server that issued it).
  • Not revealed: the viewing key, the merchant's balance, and every other transaction.
  • This page: loads nothing from other websites. The receipt in the link is sent only to the server that issued it, so it can check it. The browser check above sends nothing at all.
